03Quick start

From install to graph in three steps.

The browser package contains the component and provider adapters. Shared protocol types stay in their own package.

01

Install

Add the browser renderer and the shared protocol types.

npm i @web-git-graph/web \
  @web-git-graph/protocol
02

Register

Register the native custom element once in your browser entry.

import "@web-git-graph/web/register";

<web-git-graph id="history" />
03

Connect

Choose a provider and assign it directly to the element.

const graph = document.querySelector("#history");
graph.provider = new GitHubGitGraphProvider({
  repository: "GIS-Info/web-git-graph"
});
