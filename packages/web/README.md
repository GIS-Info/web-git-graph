# @web-git-graph/web

Framework-free Git history graph rendering, virtualized interactions, and
browser provider adapters — suited to coding-agent UIs and IDE webviews.

```ts
import "@web-git-graph/web/register";
import { GitHubGitGraphProvider } from "@web-git-graph/web/providers/github";
```

Shared Git graph DTOs are exported by `@web-git-graph/protocol`.

Agent integration: see the repo [AGENTS.md](../../AGENTS.md),
[recipes](../../docs/recipes/README.md), and
[skill](../../skills/web-git-graph/SKILL.md).
